# 検証・約定プロトコル EP-1

制定日: 2026-10-09。v0.2.0以降の新規計画に適用。過去の推薦条件へ遡及適用しない。

## 評価の分離

- 選定効果: 推薦翌営業日の始値を共通基準とする5・10・20営業日終値比。未約定候補も含める。期間は推薦翌営業日を1日目とする。
- 取引効果: 実行可能な条件で成立した仮想取引の退出損益。手数料、スリッページ、配当権利を含める。実売買とは別。
- 資金運用効果: 現金を含む日次純資産、初期資金比収益、最大ドローダウン、資金稼働率。取引リターンの単純合算を資金リターンと呼ばない。
- 実取引: 本人が提供した約定履歴だけを非公開で記録。口座には接続しない。仮想約定と混ぜない。

## 引け後の判定と翌営業日の計画

1. 確定日足のみで、候補の支持水準維持、陽線（終値>始値）、当初Entry帯への接触を判定する。高値更新が必要なら、当日終値>前営業日高値まで引け後に確認する。
2. 判定時刻、使用足の最終日、全条件、次営業日、買い上限、Stop、Target 1、期限、株数算出根拠を `history/plans.csv` に事前登録する。将来の足を参照したトリガーは禁止。
3. 翌営業日の寄り付き前に材料、決算・権利日、分割、余力、注文可能性を再確認する。変更・中止は寄り付き前に時刻付きで記録する。寄り付き結果を見て遡って中止しない。
4. 基本方式は当日限りの寄指買いと、約定後のTarget 1全数指値／Stop逆指値成行の組合せ。SBIのIFDOCOに寄指の指定が可能か、対象市場・銘柄・発注期限・親子注文期間を公式仕様と実際の利用画面で確認する。確認できない組合せは「実行条件未確認」とし、実行可能と表示しない。Codexは発注しない。
5. 買い上限以下で寄り付いたら始値を仮想価格とする。始値が上限を超えたら未約定。日中に上限へ下がっても寄指注文として約定させない。買い指値には下限防止機能がない。Stop以下への安寄りでも、注文済みなら未約定扱いに逃げず、約定・即時撤退とその順序不明リスクを記録する。
6. 反発確認日の翌日にさらに高値更新を待ってから、その日の始値で買ったことにする評価は禁止。分足で実行価格を確認できない場合は `ambiguous` とする。

## 退出と不確実な約定

- Target 1で全数退出。Target 2は参考表示に限り、事後に有利な方へ選ばない。部分利確を試す場合は別実験IDを事前登録する。
- Stopは日中到達時の逆指値成行。終値割れ判定と混同しない。翌日始値がStopを下回る場合は始値以下の約定を想定し、Stop価格で損失を固定しない。
- 指値に高値がちょうど触れただけの約定は板・約定記録がなければ未確定。高値が指値を超えた場合も全量約定は流動性仮定として明示する。
- 同日のTargetとStop両到達、寄り付かない日、子注文発注前の到達、一部約定、売買停止は日足だけで順序を断定しない。`ambiguous` とし、損切り先行と利確先行の上下限を別々に示す。都合の良い側だけ採用しない。
- 最長保有期限を推薦時に営業日の日付で固定する。期限引けで退出する場合、寄り付き前の取消・引け注文準備を手順へ明記し、既存OCOと二重注文にしない。実際の注文切替・排他性を確認できなければ約定を確定しない。
- 評価期間中の分割・併合は価格と株数の両方を調整。生OHLCVと調整係数を別保存。配当落ちを通常損失だけにせず、権利獲得時の受取配当を税引前損益へ計上。金額不明ならネット成績を未確定にする。
- 手数料はプラン・適用条件が確認できた場合だけ確定値を使う。SBI利用だけで0円としない。仮想コストは基準と悪化ケースを計画時に固定し、推定であることを明記する。実約定価格にはスリッページを二重計上しない。

## 台帳と集計

- 旧 `evaluations.csv` と `weekly_performance.csv` は旧方式の記録。`audit_status=legacy_unverified` の行を検証済み成績へ含めない。元データは `archive/pre_audit_2026-10-09/` にハッシュ付き保存。
- 全推薦の監査状態は `history/audit.csv`。新方式の結果は `history/trade_results.csv`。主キーは推薦日・銘柄・計画ID・戦略IDで、同じ取引の5/10/20日レビューを取引件数へ重複計上しない。
- `pending / open / closed / no_entry / ambiguous` を分ける。`verified` かつ `closed` の同一戦略・同一プロトコル・同一コスト条件・同一期間だけで、勝率／平均取引リターン／PFを計算する。
- ネット損益=(退出価格−約定価格)×株数+配当−手数料−仮想スリッページ費用。PF=ネット利益合計÷ネット損失絶対値合計。損失0件なら算定不能、利益0かつ損失ありなら0。引分は勝率の分母に含める。
- `mark_returns.csv` は全候補を共通価格基準で計測する専用台帳。約定基準の取引損益と混ぜない。欠損・未到来・未約定は区別する。
- MFE/MAEは約定後から退出まで。退出日の高安が退出前と確認できなければ境界不明と明記する。Stop退出後の安値を確定MAEへ含めない。
- `portfolio_daily.csv` は戦略ごとの初期資金、現金、時価、配当債権、日次純資産を残す。入出金は禁止した仮想比較を基本とし、日次欠損時は最大ドローダウンを算定しない。
- JPX営業日を使う。評価期限の到来と戦略保有期限は別。週次レビュー時に全推薦の期限を一覧照合し、未処理と理由を残す。

## 証拠の保存

`data/` に取得時刻（タイムゾーン付き）、URL、銘柄、期間、未調整OHLCV、分割係数、配当、取得不能理由を保存し、SHA-256を `data/manifest.csv` へ記録する。必要な範囲に限定し提供元の利用条件を確認する。移動平均の期間・欠損処理・RSIの初期化など計算条件も記録する。URLだけを原データ保存とみなさない。

## 公式仕様の確認先

2026-10-09確認。仕様変更時は再確認する。

- [SBI特殊注文取引ルール](https://search.sbisec.co.jp/v2/popwin/attention/trading/stock_20.html): 親子注文、対象市場、寄指、権利日を跨ぐ場合の失効・未発注条件。
- [SBI手数料無料の条件](https://faq.sbisec.co.jp/answer/64f176ea8e582c2aa5655c2a/): 適用条件を満たす場合のみ無料。
- [JPX休業日](https://www.jpx.co.jp/corporate/about-jpx/calendar/index.html): 土日祝日を除く営業日で評価。
