# 記録仕様

CSVを正本とする。空欄は不明・未到来で、0と区別する。金額は円、率は百分率（5は5%）、日付はISO、時刻はJSTオフセット付きISO。銘柄コードは文字列。実売買・個人資金は `.local/` に限定する。

| ファイル | 一行の単位 | 用途 |
|---|---|---|
| recommendations.csv | 推薦日×銘柄 | 当初推薦を固定。訂正は原本を保存して監査記録に残す |
| audit.csv | 旧推薦日×銘柄 | 旧27推薦の状態・価格・不足証拠 |
| evaluations.csv / weekly_performance.csv | 旧評価 | legacy_unverified。旧数値は書換えず新集計から除外 |
| plans.csv | plan_id | 判定時刻・翌営業日・価格・株数・期限・根拠を事前登録 |
| trade_results.csv | trade_id | 仮想約定・退出と費用。plan_idに紐付ける |
| mark_returns.csv | 推薦日×銘柄×5/10/20日 | 全候補の翌営業日始値基準リターン |
| portfolio_daily.csv | 実験×戦略×コスト×日 | 現金+時価+配当債権=純資産。初日資金からの推移 |
| universe.csv | 調査日×銘柄 | 全一次確認、各スコア、選定・見送り根拠 |
| evaluation_schedule.csv | 推薦日×銘柄×期間 | 営業日による期限・処理状況 |
| operation_log.csv | 作業日×作業 | 所要分、API費用、取得不能、報告先。未計測は空欄 |
| experiments.csv | experiment_id | 事前登録・開始日・状態・固定設定ファイル |

## 取引の状態

`pending`: 未判定、`open`: 仮想保有中、`closed`: 退出済み、`no_entry`: 期限まで未約定、`ambiguous`: 順序・約定未確定。

監査状態は別列で `verified / unverified`。verifiedはデータ・価格調整・約定時系列・費用・配当まで確認済みの意味。空の費用欄をゼロとして認定しない。各計画のsource_fileは必要な全証拠を列挙するマニフェストを指定する。パスはリポジトリ相対で公開可能なデータに限定。

公表する成績は仮想取引。部分約定・分割・複数退出は一取引へ集約する前に明細証拠を保存し、株数不一致を機械的に許可しない。EP-1初期実装では一致する全数取引のみ検証済みへ進める。

## 公開と非公開

静的サイトは許可したファイルからのみ生成する。公開モデルの仮想資金は `rules/experiment_config.json`。ユーザーの実資金、許容損失、手数料設定、実約定は公開モデルへコピーしない。

原価格・調整係数・配当・算出式・取得日時は `data/` に保存し、ハッシュをmanifestへ追加する。監査用抜粋は全期間データと区別する。旧推薦の再検証には抜粋だけでは不足する。
